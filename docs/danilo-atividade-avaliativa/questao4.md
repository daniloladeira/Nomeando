# Questão 4 - Atributos dos Requisitos

## Atributos Definidos

| Atributo            | O que representa                                                                                       |
| :------------------ | :----------------------------------------------------------------------------------------------------- |
| **Identificador**   | Código único do requisito (RF ou RNF), usado para referenciá-lo em outros documentos do projeto.       |
| **Nome**            | Nome curto que resume do que se trata o requisito.                                                     |
| **Tipo**            | Se o requisito é Funcional (RF) ou Não Funcional (RNF).                                                |
| **Prioridade**      | Grau de importância do requisito para o projeto (Alta, Média ou Baixa).                                |
| **Estado Atual**    | Fase do ciclo de vida em que o requisito se encontra hoje, conforme o modelo definido na Questão 1.    |
| **Rastreabilidade** | Documento(s) do projeto onde o requisito está detalhado (Documento de Visão e/ou História de Usuário). |
